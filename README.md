# AutoAH 1.1 (Fabric, Minecraft 1.16.5)

## Як зібрати
Потрібен JDK 17 (або 11+) і Gradle 7.3+:

    gradle build

Готовий мод буде тут: `build/libs/autoah-1.1.jar`
(файл `autoah-1.1-dev.jar` ставити в гру не потрібно).

Залежності підтягуються автоматично: Fabric Loader 0.14.21, Fabric API 0.42.0+1.16,
Yarn 1.16.5+build.10, ModMenu 1.16.23 (тільки для компіляції, у грі необов'язковий).
Якщо Gradle не знайде ModMenu — видаліть рядок `modCompileOnly` у build.gradle
та файл src/main/java/autoah/ModMenuIntegration.java (+ рядок "modmenu" у fabric.mod.json).

## Що змінено
1. Стаки зілля та інших предметів, які на сервері стакаються більше, ніж у клієнті
   (твої 21 шт.): розділення стака тепер іде через сервер, мод чекає підтвердження і
   бере рівно стільки, скільки виставлено в "Предметів у лоті" (1, 2, 3 ...).
2. Номери слотів у /ah тепер маленькі (розмір: SLOT_NUMBER_SCALE у AutoAh.java).
3. Нова швидкість "Максимум" (кілька кроків за тік, мінімальні паузи).
4. Меню в стилі Minecraft (сіра панель як в інвентарі, стандартні кнопки).
5. Увесь інтерфейс і повідомлення українською.
6. Можна обрати кілька видів предметів (перемикачі слотів 1–9 з іконками в меню).
   Кожен лот мод бере випадково з обраних видів, що ще є в інвентарі.
7. Кнопка 'Рух камери (анти-АФК)' у меню: плавно повертає камеру, поки мод працює.
